A lighter way to explore

Pass, save, or open a listing.

Each card gives you a quick first look. Use a swipe or the buttons; both lead to the same action. You stay in charge of what happens next.

♥

Keep the idea.

↑

UP / OPEN

Take a closer look.

Open the app’s F-Droid page in your browser, with an in-app web view as a fallback.

Opening a listing is not an install. Fosser helps you discover and save apps; installation and updates are handled by your chosen app source.

Your list, over time

Recommendations from your swipes.

Fosser’s deterministic recommendation engine learns from the category, developer, licence and words in app descriptions you react to. It ranks unseen apps, then spreads out similar categories so the deck does not get stuck in one lane.

⌁

No account to tune. Your swipe history and saved list are stored in the app’s local Room database.

Start with a browse

From download
to discovery.

  1. 01

    Get the release

    Download the APK from Fosser’s GitHub release. Android may ask you to allow installs from the app you used to open it. For local release builds, Gradle uses a debug key when release credentials are absent; check the release notes for the published APK details.

    ↗
  2. 02

    Let the catalogue load

    Fosser reads the official F-Droid index and caches the app data. The initial index is large—about 60 MB according to the project README.

    ↗
  3. 03

    Try the three actions

    Swipe left to pass, right to save, or up to open the F-Droid listing. Buttons offer the same choices.

    ↔
  4. 04

    Choose where to install

    Fosser opens the listing; it does not install or update apps. Continue with F-Droid or another app source you trust.

    ↗

Pick the right kind of tool

Fosser sits beside the stores.

Fosser uses F-Droid’s catalogue for discovery. The official F-Droid app and Droid-ify are the places to browse repositories, install apps and manage updates.

Tool Main job Install and update apps? A good fit when…
F Fosser Swipe-first discovery from the F-Droid catalogue No. It saves ideas and opens listings. You want a lightweight way to find and shortlist open-source apps.
F-Droid Official libre-app catalogue and client Yes. Browse, install and track updates. You want the official client and its repository workflow.
Droid-ify Third-party F-Droid-compatible client Yes. Browse and install apps; manage updates. You prefer a different client interface or installation options.

Know what uses the network

Your swipes are local. The catalogue is online.

Fosser fetches the signed F-Droid index, app icons and screenshots, and may open web listings. The project describes the app as having no account and no tracking; its swipe history and saved apps are stored in a local database. Secure-connection failures in the in-app web view are cancelled, not bypassed.

For the curious

How Fosser ranks and stores listings.

The catalogue parser streams F-Droid’s v2 index. Fosser stores app data, saved apps and swipe history with Room, then ranks the unseen catalogue using a small deterministic Kotlin engine.
